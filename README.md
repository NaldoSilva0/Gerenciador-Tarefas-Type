# Gerenciador de Tarefas — TypeScript

Meu primeiro projeto desenvolvido em **TypeScript**.

O objetivo deste projeto é praticar os fundamentos da linguagem enquanto desenvolvo um gerenciador de tarefas simples executado pelo terminal.

## 🚀 Funcionalidades

* 📋 Visualizar tarefas
* ➕ Adicionar tarefas
* 🗑️ Remover tarefas
* ✅ Concluir tarefas
* 💾 Salvar tarefas em um arquivo JSON
* 🔄 Carregar tarefas automaticamente ao iniciar o programa
* 🆔 Sistema de IDs para identificar cada tarefa

## 🛠️ Tecnologias

* TypeScript
* Node.js
* JSON
* Git e GitHub

## 📚 O que estou praticando

Este projeto está sendo desenvolvido como forma de aprendizado. Entre os conceitos praticados estão:

* Interfaces e tipagem do TypeScript
* Arrays e objetos
* Funções
* `async/await`
* Manipulação de arquivos
* JSON (`JSON.parse` e `JSON.stringify`)
* Entrada de dados pelo terminal
* Módulos do Node.js
* Git e GitHub

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/NaldoSilva0/Gerenciador-Tarefas-Type.git
```

Entre na pasta:

```bash
cd Gerenciador-Tarefas-Type
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
node src/gerenciador.ts
```
